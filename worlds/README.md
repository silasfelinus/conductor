# Shared story worlds

Story universes are not Conductor projects. Projects own tasks, output, and lifecycle; world
directories own **cross-project discovery and canon precedence**. This prevents a new
project/Project row from being invented merely to catalogue work.

- [Zuzu: Koala Assassin](zuzu/README.md) — shared story, character, art, LoRA and production references.

When authoring something in an existing world, start with its README and machine-readable
`catalog.json`. Keep original scripts, ArtImages, Resources, and project files in their
existing homes. A catalogue entry links to the source; it is not a replacement copy.
