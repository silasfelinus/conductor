# Garden Gate, Four Movements

## Teaching purpose

This controlled comparison keeps one quiet garden-gate composition fixed while changing only the movement-level visual language. Students should learn to identify which cues belong to composition, which belong to material and mark-making, and which belong to the historical style.

The sequence is suitable for an Academy lesson, a blind-comparison exercise, or a future four-image inspiration strip. It is not a request to imitate any living artist.

## Fixed source composition

Use the same source image for every variation:

- a waist-high wooden garden gate, slightly open
- a narrow path leading through dense plants
- one small watering can beside the gatepost
- late-afternoon light entering from the upper left
- no people, text, logos, or modern branded objects
- square crop with the gate occupying the lower-center third

Keep the camera position, object count, path direction, and major silhouettes stable. The point is comparison, not four unrelated pretty gardens.

## Movement 1 — Impressionism

### Recognition cues

- broken, visible brushwork
- high-key outdoor light
- colored shadows rather than neutral gray
- softened edges and atmospheric depth
- transient light taking priority over botanical detail

### Remix prompt

> Preserve the garden gate, path, watering can, viewpoint, and object placement. Translate the scene into an Impressionist outdoor study with broken brushstrokes, luminous late-afternoon color, softened edges, colored shadows, and flickering light across the leaves. Keep the scene observational and airy rather than polished or photorealistic.

### Negative guidance

- no hard vector outlines
- no glossy 3D rendering
- no photographic depth of field
- no hyper-detailed individual leaves
- no artist names

### Common failure

A generic oil-paint filter often adds texture without changing the light logic. A successful result should make changing light and atmosphere feel like the subject.

## Movement 2 — The Nabis

### Recognition cues

- flattened depth
- decorative color areas
- simplified contours
- patterned foliage and surfaces
- an intimate domestic or garden mood

### Remix prompt

> Preserve the same gate, path, watering can, viewpoint, and silhouettes. Recompose the scene through the movement-level language of the Nabis: flattened spatial depth, simplified dark contours, decorative color blocks, patterned foliage, and an intimate garden atmosphere. Let surface rhythm matter more than realistic perspective.

### Negative guidance

- no named artists
- no deep photographic perspective
- no realistic leaf-by-leaf rendering
- no comic-book inking
- no generic anime styling

### Common failure

The model may turn “decorative” into wallpaper pasted over a realistic scene. The path and plants should themselves become flattened rhythmic shapes.

## Movement 3 — Precisionism

### Recognition cues

- crisp geometric simplification
- controlled edges and smooth surfaces
- strong light-and-shadow planes
- reduced clutter
- calm, almost engineered spatial order

### Remix prompt

> Preserve the garden gate, path, watering can, viewpoint, and major silhouettes. Interpret the composition through Precisionism using crisp geometric simplification, controlled edges, broad planes of light and shadow, reduced visual clutter, and a quiet engineered order. Treat the gate and path as precise structural forms while keeping the setting recognizably domestic.

### Negative guidance

- no factories, smokestacks, or added skyscrapers
- no chrome science-fiction surfaces
- no painterly smearing
- no photorealism
- no named artists

### Common failure

The model may replace the garden with industrial architecture because Precisionism is strongly associated with machines and cities. The exercise is specifically about applying its formal logic to an ordinary garden.

## Movement 4 — Tonalism

### Recognition cues

- restrained, closely related color family
- softened forms
- quiet atmosphere
- broad value masses
- mood and dusk-like unity over descriptive detail

### Remix prompt

> Preserve the same garden gate, path, watering can, viewpoint, and object placement. Translate the scene into Tonalist visual language with a restrained family of muted greens, browns, and blue-gray light; softened forms; broad value masses; and a hushed, contemplative atmosphere. Keep the gate readable while allowing the garden to merge gently into mood.

### Negative guidance

- no pitch-black gothic horror
- no bright rainbow palette
- no sharp digital outlines
- no photographic fog effects
- no named artists

### Common failure

Muted color alone is not enough. The result should unify the whole scene into a narrow emotional and value range without losing the composition.

## Blind comparison exercise

Show the four images without movement labels and ask learners to identify:

1. Which version prioritizes fleeting light?
2. Which flattens the garden into decorative surface rhythm?
3. Which makes the gate feel most geometric and engineered?
4. Which compresses color and value into a unified mood?

Require one visible cue as evidence for every answer. “It feels like it” is not yet art history; it is merely vibes wearing a tiny beret.

## Reflection prompts

- Which visual decisions changed even though the source composition did not?
- Which movement preserved natural depth most strongly, and which rejected it?
- Did any result rely on a stereotype of the movement rather than its formal structure?
- Which prompt phrase had the clearest visible effect?
- What would need revision before using the set as public teaching material?

## Reproducibility record

Record for every generated image:

- source image identifier and checksum
- generation engine and exact model version
- prompt text and negative guidance
- seed
- width and height
- sampler, steps, guidance, and strength where applicable
- any LoRA path, trigger, and weight
- generation date
- ArtJob and ArtImage identifiers when generated through Kind Robots

Use one fixed seed for the first comparison pass. A second pass may vary the seed only after the prompt comparison is complete.

## Rights and representation gate

- Use a user-owned or clearly public-domain source image.
- Teach movements through movement-level language; do not put protected artist names into generation presets.
- Verify every displayed historical artwork independently for item-level public-domain or open-access status.
- Do not imply that a generated image is an authentic work from the historical movement.
- No cultural-identity transformation is requested in this object-and-landscape exercise.

## Promotion criteria

Promote this set to the Academy front end only when:

- all four outputs preserve the fixed composition closely enough for comparison
- each output demonstrates at least three recognition cues
- prompts and metadata are complete and reproducible
- the Precisionist version does not escape into a generic factory scene
- the Nabis version changes spatial and surface logic rather than adding a decorative overlay
- all source and display rights are verified
