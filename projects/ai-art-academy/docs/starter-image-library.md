# AI Art Academy — Starter Image Library (curation plan)

date: 2026-07-10
status: plan (task t-006) — download + manifest happens in a kind_robots follow-up task
policy: every entry passes PUBLIC-DOMAIN-POLICY.md §1.3 (artist died before 1956 AND
work created/published 1930 or earlier) and §2 (accepted digitization grant).

These are the images a user can remix **without uploading anything**. Selection
criteria: a clear focal subject, strong readable composition, and enough structure
that Kontext can restyle it across wildly different movements without the result
collapsing — portraits, landscapes, animals, still life, cityscapes, sea, botanical.
Iconic works are a feature, not a bug: "remix the Great Wave as Art Nouveau" is the
lesson payoff in one sentence.

**Verification status**: 11 of 21 entries were verified this session against a live
official open-access page (marked ✅ VERIFIED — museum object page or API record
confirmed via web search; the sandbox proxy blocked direct page fetches, so
verification is search-index confirmation of the exact official URL + accession).
Unverified entries (⏳) carry a best-known URL and MUST be re-verified at download
time before entering the manifest.

## Hosting: local copies + manifest (not hotlinking)

**Recommendation: download every image into
`kind_robots/public/images/academy/starters/` and ship a manifest file alongside
(`starters.manifest.json`), one provenance record per image using the policy §3
schema** (workTitle, artist, artistDied, year, collection, accessionId, sourceUrl,
license, licenseTermsUrl, retrievedDate) plus `file` (local path) and optional
`width/height/bytes`.

Why local + manifest beats hotlinking:

1. **Reliability.** Museum image CDNs throttle, move, and rot. The Met and AIC
   explicitly encourage download-and-reuse under CC0; hotlinking makes our remix
   studio's first paint depend on six third-party servers.
2. **Politeness.** Hotlinking offloads our bandwidth onto nonprofit museums —
   legal under CC0, but rude at product scale.
3. **Performance and control.** Local copies get our own resizing, thumbnails,
   caching headers, and consistent color management; Kontext needs a stable input
   URL, and our own origin is the only one we control.
4. **License snapshots.** The manifest freezes what we verified and when
   (`retrievedDate`). If an institution later changes its open-access terms, the
   images we already took under CC0 remain irrevocably CC0 — the manifest is the
   proof of what we relied on.
5. **Provenance in the UI for free.** The remix studio can show "Great Wave —
   Hokusai, ca. 1830–32, The Met (CC0)" straight from the manifest, which is both
   good pedagogy and the visible face of our public-domain policy.

Suggested file naming: `{slug}-{collection}-{accessionId}.jpg` (e.g.
`great-wave-met-jp1847.jpg`), slugs stable so curriculum entries can reference them.
Download at the largest available size; generate 512px picker thumbnails at build
time. Total footprint for 21 images at web resolution: roughly 40–80 MB — fine for
`public/`, but if kind_robots prefers a slimmer repo, the originals can live in
object storage with only thumbnails + manifest committed (decide in the follow-up
kind_robots task).
