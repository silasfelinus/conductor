# Sketchy Skill Ladder and Assignment Taxonomy

Sketchy should feel like a friendly drawing coach: clear assignment, quick win, constructive critique, then a next study that is specific enough to actually do. This ladder defines the first MVP taxonomy for assignment generation and critique routing.

## Goals

- Give users assignments that match their current skill without making them choose from a giant art-school menu.
- Keep every task small enough to complete in one focused session.
- Make critique actionable: every score should point to the next assignment family.
- Support playful themes without making the core skill model chaotic.

## Skill levels

### Beginner

Beginner assignments build confidence and observation habits. They should avoid long compositions, complex anatomy, and high-detail rendering.

Default constraints:

- 5–20 minute assignment window.
- 1–3 subjects or forms.
- Clear success criteria visible before the user starts.
- Reference allowed and encouraged.
- Critique focuses on one or two improvements only.

Typical prompt wording:

> Draw three simple household objects as basic forms. Use boxes, cylinders, and spheres. Do not shade yet; focus on clean proportions.

### Intermediate

Intermediate assignments combine two or three fundamentals. They can ask for partial scenes, timed figure studies, controlled value, and stylized simplification.

Default constraints:

- 20–60 minute assignment window.
- 2–4 required criteria.
- Reference encouraged, but the user may invent from imagination.
- Critique identifies one strength, one priority fix, and one targeted follow-up.

Typical prompt wording:

> Draw a small street-corner scene using two-point perspective. Include three simple props and one character silhouette. Use three value groups only.

### Advanced

Advanced assignments ask for finished decision-making: composition, intent, value control, style, visual storytelling, and revision.

Default constraints:

- 45–120 minute assignment window.
- 3–6 required criteria.
- Multiple passes are allowed: thumbnail, rough, cleanup, value or color pass.
- Critique can include tradeoffs and revision suggestions.

Typical prompt wording:

> Design a finished character illustration for a tired space botanist. Show personality through pose, props, silhouette, and value hierarchy. Include one thumbnail sheet or alternate pose note.

## Difficulty knobs

Sketchy should generate assignments by combining a category, skill level, and a few difficulty knobs.

| Knob | Beginner | Intermediate | Advanced |
| --- | --- | --- | --- |
| Time | 5–20 min | 20–60 min | 45–120 min |
| Subject count | 1–3 | 2–5 | scene or full design |
| Reference | required or suggested | suggested | optional but documented |
| Construction | basic forms | forms plus proportion | forms, gesture, anatomy, composition |
| Value | none or 2 values | 3–5 values | designed hierarchy |
| Perspective | flat or 1-point | 1–2 point | complex camera or environment |
| Anatomy | stick/bean/simple mannequin | simplified figure | expressive figure, hands, faces, drapery |
| Finish | sketch | cleaned study | portfolio-style pass |
| Critique depth | one priority | strength + fix + next task | revision path + next challenge |

## Assignment categories

### Fundamentals

Core observation, line confidence, proportions, and form thinking.

Beginner samples:

- Draw 10 straight lines, 10 curves, and 10 ellipses; circle the cleanest three of each.
- Draw one mug as a cylinder and box combination, then label the main forms.
- Copy a simple object twice: once slowly, once in under three minutes.

Intermediate samples:

- Draw a pair of shoes using simplified boxes and cylinders before adding contour.
- Create a page of 12 object thumbnails using only basic forms.
- Draw the same object from three angles using construction lines.

Advanced samples:

- Build a complex prop, such as a bicycle or coffee grinder, from major forms first.
- Design three readable silhouettes for the same object with different moods.
- Redraw an old sketch with visible construction and cleaner proportions.

### Gesture

Fast movement, rhythm, action, and pose readability.

Beginner samples:

- Do eight 30-second stick-figure action poses from reference.
- Draw five animal poses using only a line of action and two body masses.
- Turn three emoji moods into simple body poses.

Intermediate samples:

- Do six 2-minute figure gestures emphasizing weight and balance.
- Draw one character walking, reaching, and turning using the same body proportions.
- Sketch a dancer or athlete in three stages of the same action.

Advanced samples:

- Create a dynamic action pose with clear silhouette, twist, and weight shift.
- Draw a two-character interaction where the emotion reads from posture alone.
- Convert a stiff pose into three more energetic gesture variations.

### Shape

Graphic design, silhouette, simplification, and shape language.

Beginner samples:

- Draw three monsters using only circles, triangles, and squares.
- Redesign one object as cute, spooky, and fancy using shape language.
- Fill a page with 20 tiny silhouettes and star the five most readable.

Intermediate samples:

- Design three shop signs using distinct silhouettes and no text.
- Turn a random object into a character by changing only its shapes.
- Create a hero, sidekick, and villain silhouette set with clear contrast.

Advanced samples:

- Build a character lineup where each role is readable from silhouette alone.
- Redesign a vehicle or building in three genres using shape language.
- Make a finished black-and-white poster composition using only flat shapes.

### Value

Light, shadow, grouping, focal point, and readability.

Beginner samples:

- Shade a sphere, cube, and cylinder with one light source.
- Make a two-value study of a simple photo: light shapes and dark shapes only.
- Draw an object using only three tones: white, gray, black.

Intermediate samples:

- Create a five-value still life from three objects.
- Turn a messy sketch into a clear three-value composition.
- Paint a tiny scene where the focal point is the highest contrast area.

Advanced samples:

- Design a cinematic value study for a character entering a doorway.
- Create three lighting moods for the same sketch: morning, storm, stage light.
- Revise a composition by grouping values more clearly, not by adding detail.

### Perspective

Space, depth, camera, and believable construction.

Beginner samples:

- Draw a hallway in one-point perspective with three doors.
- Draw five boxes above, below, and at eye level.
- Place a simple table and chair in the same perspective grid.

Intermediate samples:

- Draw a corner room in two-point perspective with three props.
- Sketch a small market stall with boxes, cylinders, and hanging signs.
- Draw a vehicle or robot from a three-quarter view using box construction.

Advanced samples:

- Design a room from an unusual camera angle and keep objects aligned.
- Draw a street scene with overlapping depth, scale figures, and atmosphere.
- Create a fantasy doorway or portal with believable perspective anchors.

### Anatomy

Figure construction, faces, hands, bodies, proportion, and expression.

Beginner samples:

- Draw a simple mannequin in front, side, and three-quarter view.
- Draw 12 hands as mitten shapes with thumb placement only.
- Draw five faces using the same head construction and different expressions.

Intermediate samples:

- Draw a torso and pelvis bean in six poses.
- Study hands holding three different simple objects.
- Draw a character turnaround with consistent head and body proportions.

Advanced samples:

- Draw a clothed figure where folds support the gesture and anatomy.
- Design five expressive faces for the same character without changing identity.
- Draw a complex seated pose with hands, feet, and believable weight.

### Character design

Identity, costume, personality, silhouette, props, and visual storytelling.

Beginner samples:

- Design a character from three words: shy, mushroom, explorer.
- Draw the same character as happy, nervous, and determined.
- Give a simple blob character three costumes that show different jobs.

Intermediate samples:

- Design a character sheet with front pose, expression, and one important prop.
- Create a hero and rival using opposite shape language.
- Redesign a normal person as a fantasy shopkeeper without over-detailing.

Advanced samples:

- Make a mini lineup for a story party: leader, trickster, guardian, wildcard.
- Create a polished character concept with callouts for costume and props.
- Design a character whose backstory is readable before reading any text.

### Environments

Places, atmosphere, storytelling spaces, and prop relationships.

Beginner samples:

- Draw a cozy desk corner with three objects and simple perspective.
- Sketch a tiny house exterior using boxes and a triangle roof.
- Draw the same tree in sunny, windy, and spooky moods.

Intermediate samples:

- Design a small shop interior with a clear path and focal point.
- Draw a campsite at night using three value groups.
- Create a map-like thumbnail for a fantasy room or garden.

Advanced samples:

- Paint a story environment where something just happened.
- Design a location that reveals who lives there through props and wear.
- Create three thumbnails for the same environment with different camera angles.

### Style studies

Learning through analysis, remixing, and controlled imitation without copying final work directly.

Beginner samples:

- Pick an artist or cartoon style and identify three visual rules it uses.
- Redraw a simple object in a chunky, elegant, and scribbly style.
- Make a page of line samples inspired by a reference style.

Intermediate samples:

- Draw an original character using three observed style rules from a chosen reference.
- Study how a favorite artist handles eyes, hands, and folds; make small practice notes.
- Convert a realistic object into a simplified icon style.

Advanced samples:

- Create an original scene using a style recipe you write first.
- Blend two influences into a new, named style with three rules.
- Redraw one of your older works in a more deliberate style direction.

### Finished pieces

Longer assignments that combine planning, execution, and revision.

Beginner samples:

- Finish a clean postcard-sized drawing of one object with simple shading.
- Make a tiny illustrated badge for a hobby you love.
- Create a finished black-and-white creature design using three values.

Intermediate samples:

- Complete a character portrait with readable expression, prop, and value grouping.
- Make a small environment illustration with foreground, middle ground, and background.
- Create a finished cover thumbnail for an imaginary short story.

Advanced samples:

- Complete a polished illustration with thumbnail, rough, value plan, and final pass.
- Design a portfolio-style character or environment sheet with annotations.
- Revise an earlier finished piece after critique, then compare before and after.

## Assignment generator shape

Each generated assignment should include:

- `title`: short and motivating.
- `category`: one of the taxonomy categories above.
- `level`: beginner, intermediate, or advanced.
- `estimatedMinutes`: realistic completion window.
- `prompt`: the drawing task.
- `materials`: pencil, ink, tablet, grayscale, color, etc.
- `constraints`: 2–5 concrete rules.
- `successCriteria`: what the critique should check first.
- `stretchGoal`: optional bonus for users who finish early.
- `nextLikelyCategories`: 1–3 categories to choose from after critique.

Example:

```yaml
title: Cozy Desk Corner
category: environments
level: beginner
estimatedMinutes: 20
materials:
  - pencil
  - grayscale optional
constraints:
  - Use one-point perspective.
  - Include exactly three objects on the desk.
  - Keep shading to two values.
successCriteria:
  - The desk plane is readable.
  - The objects sit on the surface instead of floating.
  - The focal object is clear.
stretchGoal: Add one tiny story detail that tells us who uses this desk.
nextLikelyCategories:
  - perspective
  - value
  - fundamentals
```

## Critique-to-next-assignment routing

The critique engine should select a next assignment using the user's weakest high-impact skill, not the most numerous mistake.

Routing examples:

- Wobbly linework but good idea → fundamentals line confidence study.
- Stiff pose but good proportions → gesture study.
- Confusing silhouette → shape assignment.
- Muddy focal point → value grouping assignment.
- Floating objects → perspective placement assignment.
- Awkward hands or face → anatomy micro-study.
- Pretty rendering but generic design → character design or environment storytelling.
- Strong study across the board → finished piece or style study.

## Friendly progression rules

- Never give two harsh correction drills in a row. Follow a difficult critique with a confidence-building assignment.
- Prefer short loops early: assignment → upload → one priority fix → next task.
- Offer theme skins without changing the skill target: cozy, goblin, sci-fi, magical library, noir, cute robot, etc.
- Let users skip a category once, but keep recurring weaknesses visible in the profile.
- Celebrate consistency as much as raw skill. Drawing goblin morale matters.

## MVP scope

Include in the first implementation:

- The nine categories above.
- Three skill levels.
- 5–10 hand-authored seed assignments per category.
- Assignment generator output shape.
- Critique routing rules.

Defer until later:

- Full curriculum scheduling.
- Social challenges.
- Public galleries.
- Complex style-transfer scoring.
- Paid-tier limit enforcement details, which belong in `sketchy/t-004`.
