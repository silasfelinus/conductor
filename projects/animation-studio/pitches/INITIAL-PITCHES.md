# Animation Studio — Initial Pitch Queue

## 1. Gravity Garden — building now
Luminous seeds orbit an invisible center while soft vine-like fields breathe across the screen.
Optional click: a gravity bloom pushes seeds outward before they reform. Canvas 2D, passive-first,
reduced-motion lowers particle and field counts.

## 2. Impossible Terrarium
A tiny ecosystem slowly assembles itself from drifting geometric spores: moss islands, crystal
stems, miniature weather, and migrating lights. Optional hover changes local weather without being
required. Canvas 2D or lightweight WebGL; high novelty, moderate implementation risk.

## 3. Moonlit Laundry
Clotheslines cross a sleepy rooftop while impossible garments gently animate: constellation socks,
a coat full of fireflies, a scarf that becomes a river. Optional click causes one item to perform a
brief surprise. SVG/CSS; low performance risk and strong personality.

## 4. Recursive Windows
Softly glowing windows drift through architectural spaces; each contains a tiny different scene,
and occasionally one opens into another layer. Optional click briefly visits a window before the
composition settles back. Canvas 2D; careful recursion cap required.

## 5. Jellyfish Library
Transparent jellyfish carry tiny books and bookmarks through a dark ocean-library. Shelves emerge
and fade as currents move. Optional pointer proximity causes a jellyfish to reveal a book title.
Canvas 2D; accessible without interaction.

## 6. Weather Machine for Ants
A tabletop brass machine generates miniature clouds, rainbows, snow, lightning, and tiny migrating
storms inside glass tubes. Optional click changes the next weather event. SVG + Canvas particles;
strong delight, moderate asset-design effort.

## 7. Dream Conveyor
A quiet conveyor carries strange dream objects across the screen: bottled sunsets, sleeping moons,
folded doorways, and polite ghosts. Rare combinations create surprise scenes. Optional click stamps
an object with a whimsical label. DOM/CSS or Canvas; deterministic seed useful for testing.

## 8. Magnetic Sand Choir
Colored grains flow into shifting cymatic patterns as if responding to unheard music. The motion is
fully autonomous and audio-free. Optional click introduces a temporary second magnetic pole. WebGL
preferred, with Canvas fallback and static reduced-motion composition.

## Selection rubric
Score each pitch from 1–5 for passive beauty, surprise, originality, startup safety, reduced-motion
quality, performance confidence, polish potential, and implementation effort. Reaction history on
actual attempts outranks speculative pitch scores once builds exist.
