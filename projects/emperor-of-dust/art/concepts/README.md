# Emperor of Dust · Fortress Visual Exploration

**Status:** concept studies, not approved production illustration or generated ArtJobs.
**Sources:** `projects/emperor-of-dust/MAP-LAYOUT.md`, `SYSTEMS-V03.md`, `DAILY-DREAM-VIBE.md` on Conductor. The v0.3 50-day design takes precedence over superseded 100-day and Horde drafts.

## Map art
- `wasteland-base.svg`: unlabeled reusable strategy-map base (no gameplay markers).
- `wasteland-reference.svg`: labelled geographical guide; sample Day 1 fog shown as a reference, not painted into the base.
- `wasteland-day41-overlay.svg`: transparent illustration of the final-act fracture overlay, not an in-game event renderer.
- `fortress-cutaway-base.svg`: five-room architectural base with archive, yard and gatehouse.
- `fortress-cutaway-reference.svg`: room-labelled internal guide.

## Main screens
- `screen-throne.svg`: audience dialogue, consequences, Komodo advisory scene.
- `screen-quests.svg`: quest notices, follower assignment/odds, expiry.
- `screen-barracks.svg`: beds, recovering followers, portrait-focused conversations.
- `screen-market.svg`: rotating stock, healing, brass economy.
- `screen-map.svg`: table-top territorial view, tax and affinity panels.
- `screen-chronicle.svg`: rewind/save and dawn report composition study.

Each SVG is fully editable vector art, 1600×900 for screen studies or 1600×1000 for maps. PNG previews are included in the separate preview ZIP. On mobile, display the room art as a single fitted stage with secondary choices as a bounded drawer. Art-heavy composition is intentional; real interactive controls need semantic HTML layered over the scene.

## Integration and approvals

Keep illustration assets separate from interactive overlays for faction crests, town names, fog, warnings and animated act changes. The real site renders text for localization and accessibility, never as a baked map label. These mockups show layouts and props, not character design locks; substitute existing canonical assets before using them as production portraits. No production ArtJobs were queued, no project images attached, and no public release is authorized. This pack is for human art-direction approval and subsequent in-site ArtJob generation.
