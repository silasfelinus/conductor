# Hollywood Recast

Canonical slug: `hollywood-recast`

Canonical title: **Hollywood Recast**. It is not “Hollywood Recast 2.”

This is book two in the coloring-book production order. The older shorthand `HR`
was also used for Monster Recast, so files, proposal ids, jobs, and notes for this
book use the `hwr-` prefix.

inspirations, accepted working files, and confirmed final color/BW pairs should be
recorded there as they are developed. The cover is separate.
