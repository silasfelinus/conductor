# Kind Robots Coloring Book

Canonical slug: `kind-robots`

This is book three in the coloring-book production order, after Monster Recast and
Hollywood Recast.

`proposals.yaml` owns the 36 interior proposal slots. Existing Kind Robots art may
be attached as inspiration or candidate source material, but directory presence or
prior publication does not automatically make an image an accepted coloring-book
master. Record accepted and final color/BW files explicitly. The cover is separate.
