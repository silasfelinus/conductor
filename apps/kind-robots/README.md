# Kind Robots

Scaffolded by AppMaker (`scripts/new_app.py`). See `apps/README.md` for the
workshop conventions and `projects/kind-robots/roadmap.yaml` for the plan.

First checkout on a dev machine:

```sh
cd apps/kind-robots
flutter create . --org org.kindrobots --project-name kind_robots --platforms ios,android
flutter pub get
flutter test
```
