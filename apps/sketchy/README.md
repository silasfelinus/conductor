# Sketchy

Scaffolded by AppMaker (`scripts/new_app.py`). See `apps/README.md` for the
workshop conventions and `projects/sketchy/roadmap.yaml` for the plan.

First checkout on a dev machine:

```sh
cd apps/sketchy
flutter create . --org org.kindrobots --project-name sketchy --platforms ios,android
flutter pub get
flutter test
```
