# AppMaker

Scaffolded by AppMaker (`scripts/new_app.py`). See `apps/README.md` for the
workshop conventions and `projects/appmaker/roadmap.yaml` for the plan.

First checkout on a dev machine:

```sh
cd apps/appmaker
flutter create . --org org.kindrobots --project-name appmaker --platforms ios,android
flutter pub get
flutter test
```
