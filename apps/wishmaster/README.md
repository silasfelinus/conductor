# Wishmaster

Scaffolded by AppMaker (`scripts/new_app.py`). See `apps/README.md` for the
workshop conventions and `projects/wishmaster/roadmap.yaml` for the plan.

First checkout on a dev machine:

```sh
cd apps/wishmaster
flutter create . --org org.kindrobots --project-name wishmaster --platforms ios,android
flutter pub get
flutter test
```
