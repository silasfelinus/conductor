# Recipe Box

Scaffolded by AppMaker (`scripts/new_app.py`). See `apps/README.md` for the
workshop conventions and `projects/recipe-box/roadmap.yaml` for the plan.

First checkout on a dev machine:

```sh
cd apps/recipe-box
flutter create . --org org.kindrobots --project-name recipe_box --platforms ios,android
flutter pub get
flutter test
```
