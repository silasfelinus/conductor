# Storybook

Scaffolded by AppMaker (`scripts/new_app.py`). See `apps/README.md` for the
workshop conventions and `projects/storybook/roadmap.yaml` for the plan.

First checkout on a dev machine:

```sh
cd apps/storybook
flutter create . --org org.kindrobots --project-name storybook --platforms ios,android
flutter pub get
flutter test
```
