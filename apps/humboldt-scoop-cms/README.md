# Humboldt Scoop Solutions

Scaffolded by AppMaker (`scripts/new_app.py`). See `apps/README.md` for the
workshop conventions and `projects/humboldt-scoop-cms/roadmap.yaml` for the plan.

First checkout on a dev machine:

```sh
cd apps/humboldt-scoop-cms
flutter create . --org org.kindrobots --project-name humboldt_scoop_cms --platforms ios,android
flutter pub get
flutter test
```
