# Media Watchlist

Scaffolded by AppMaker (`scripts/new_app.py`). See `apps/README.md` for the
workshop conventions and `projects/media-watchlist/roadmap.yaml` for the plan.

First checkout on a dev machine:

```sh
cd apps/media-watchlist
flutter create . --org org.kindrobots --project-name media_watchlist --platforms ios,android
flutter pub get
flutter test
```
