# Storymaker

Scaffolded by AppMaker (`scripts/new_app.py`). See `apps/README.md` for the
workshop conventions and `projects/storymaker/roadmap.yaml` for the plan.

First checkout on a dev machine:

```sh
cd apps/storymaker
flutter create . --org org.kindrobots --project-name storymaker --platforms ios,android
flutter pub get
flutter test
```
