# Pitch: Kind Memory Match
date: 2026-10-04
project-target: new
status: awaiting-silas

## The idea
A card-flip matching game using pre-generated Kind Robots portraits, with three board sizes and a daily seeded layout so everyone plays the same board. Matching a pair reveals a short hand-written line about that robot, and fastest times save on the device.

## Why it's worth doing
It needs no LLM at runtime, so it is free for every visitor. Art plan: 24 square robot portraits plus three card-back designs, generated through ArtJobs in one style.

small

## Suggested first task
8 portraits, the flip and match logic on a 4x4 board, and a move counter.
