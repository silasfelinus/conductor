# Pitch: Lamp Lighter Run
date: 2026-10-09
project-target: kr-arcade
status: approved

## The idea
An arcade cabinet riffing on Donkey Kong's climb-the-girders ladder-and-barrel dodge, where a lamplighter robot hops rolling gloom-balls and climbs a scaffold to relight every street lamp. Each level adds steeper ramps, faster barrels and a bonus lantern timer.

## Why it's worth doing
It needs no LLM at runtime, so it is free for every visitor. Art plan: Cabinet marquee, lamplighter sprite sheet, gloom-ball sprites, scaffold tiles and 3 night-street backdrops generated ahead of time.

## Rough effort
medium

## Suggested first task
Intro splash, one scaffold screen with ladders and ramps, rolling hazards, jump, a bonus timer and a score submit.
