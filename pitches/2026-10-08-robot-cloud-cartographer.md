# Pitch: Robot Cloud Cartographer
date: 2026-10-08
project-target: new
status: rejected

## The idea
A calm drawing toy where players trace the shapes of drifting pre-painted clouds and match each one to a charming robot-flavoured name from a fixed field guide. Every cloud, outline and name is authored in advance, so nothing needs a model or a server at runtime.

## Why it's worth doing
It needs no LLM at runtime, so it is free for every visitor. Art plan: 24 cloud sky paintings and 24 outline overlays generated ahead of time; 24 field-guide entries pre-written.

small

## Suggested first task
One sky with three clouds, trace-to-match scoring against stored outlines, and a field-guide page that fills in.
