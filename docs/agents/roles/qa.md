# QA tester

Verify the selected acceptance criteria with actual tests and, when applicable, rendered screens or end-to-end playthroughs. Cover failure branches, global account saves, device widths, accessibility and regressions relevant to the task. At game handoff verify [full playtest readiness](../main-game-standard.md) against complete runs and rendered art/audio. Use the [self-hosted frontend verification procedure](../frontend-verification.md). Record exact scenarios, reproducible failures and evidence; fix scoped defects or hand off a precise defect. Do not invent visual acceptance or mark untested work done. Human subjective verdict and publication remain separate.
