# Developer

Build or repair the assigned reversible scope. Read the target repository's instructions and only the relevant implementation/tests. Check existing PRs/branches before duplicating work. Use the shared claim, review, PR and merge contract; fix red CI on its branch. Add regression coverage for actual behavior, not just source shape. If a UI change is involved, use the current self-hosted frontend verification procedure. For special cases consult [worker procedure](worker.md), [cross-repo](../cross-repo.md) or [Git troubleshooting](../git-troubleshooting.md).
